# M0 — Repository Foundation & Walking Skeleton

**Status:** Approved and frozen — 2026-07-26
**Basis:** `ARCH-GOV-002` (architecture, frozen) · `IMPL-GOV-001` (implementation plan, frozen)

## What Was Built

A real, thin, end-to-end vertical slice through every architectural seam — not stubs standing in for later work:

- **Canonical domain schemas** — `DecisionEvent`, `Finding`, `GovernanceVerdict`, all immutable, all validated (Pydantic v2, timezone-aware timestamps, bounded confidence scores).
- **Adapter port + one reference implementation** — `Adapter[TPayload]` (generic, ABC-based) and `SyntheticAdapter`, proving genuine field-level translation from a source system's wire format into the canonical schema.
- **Normalization pass** — structural normalization only (whitespace, timezone, feature precision); protected-attribute resolution is explicitly out of scope until M2.
- **Policy port + one reference implementation** — `Policy` (ABC) and `AlwaysAllowPolicy`, proving the evaluation contract.
- **Governance Engine** — wraps a single `Policy`'s `Finding` into a `GovernanceVerdict`; a deliberately minimal two-state (`ALLOW`/`FLAGGED`) placeholder ahead of M5's full four-state model with bindings, escalation, and signing.
- **Evidence Store** — SQLite-backed, hash-chained (SHA-256, genesis-anchored), append-only at the application layer, with real cryptographic chain linkage verified under concurrent writes.
- **FastAPI service** — a composition-root app factory (`create_app`), `/healthz`, and `POST /v1/ingestion/events`; a global exception handler (closing a real V1 gap — unhandled errors no longer leak tracebacks); a request-body-size-limiting middleware.
- **Full engineering tooling** — `ruff`, `mypy --strict`, `pytest` with an enforced coverage floor, `pre-commit`, GitHub Actions CI (lint/type-check/test + a Docker build-and-smoke-test job), a `Dockerfile`/`docker-compose.yml`, and a pinned `requirements-lock.txt` generated from a verified-clean environment.
- **V1 retired** — the original single-domain prototype archived unmodified to `legacy_v1/`, superseded by this design.
- **A finalization pass** — an internal production-readiness review found 2 High and ~10 Medium findings; both High findings and every in-scope Medium finding were fixed prior to freeze (see "Remaining Deferred Items" for what was intentionally left alone, and to whom).

## Final Architecture (as built)

```
src/gov_platform/
  config/            Settings (env-driven, GOV_PLATFORM_ prefix)
  observability/     Structured JSON logging (stdlib-only)
  schemas/           DecisionEvent, Finding, GovernanceVerdict
  adapters/          Adapter[TPayload] port + SyntheticAdapter
  normalization/     NormalizationService (structural pass only)
  policy_engine/     Policy port + AlwaysAllowPolicy
  governance_engine/ GovernanceEngine (single-policy → verdict)
  audit/             EvidenceStore (hash-chained, SQLite, append-only)
  api/
    app.py           Composition root (create_app factory)
    asgi.py          The only module that constructs the default instance
    dependencies.py  DI providers — typed against ports, not concretions
    middleware.py     MaxBodySizeMiddleware
    health.py        GET /healthz
    ingestion/        POST /v1/ingestion/events
infra/docker/         Dockerfile, docker-compose.yml
.github/workflows/    ci.yml (lint, type-check, test, Docker smoke test)
tests/                unit/ (one module per source module) + integration/
legacy_v1/            Superseded V1 prototype, unmodified, reference only
```

Data flow: `Adapter.translate` → `NormalizationService.normalize` → `GovernanceEngine.govern` → `EvidenceStore.append` → `IngestionResponse`. Every step is a real, independently-tested implementation; nothing is mocked in the integration path.
